Non-negotiable boundaries

  1. Physical/reference application ISA: RISC-V. No ARM substitute, Linux guest, hosted userspace executable, or dependency on default OpenSBI in the G1 boot path.
  2. Maintained target software and project compiler/runtime logic: Lean 4. Host-only shell/Python/Nix/YAML may orchestrate builds, run tests and inspect artifacts. Host tools may use their normal runtimes; those runtimes must not enter the target image.
  3. No maintained target .c, .cc, .cpp, .rs, .zig, .s, or .S files. Lean-authored structured primitive lowering may generate narrowly scoped startup, CSR and MMIO code. A C/assembly program hidden in a Lean string is not compliance.
  4. Use a genuine Lean elaboration path for source declarations and inspect reachable runtime dependencies. A manually constructed demonstration AST or LLVM text printer is not a compiler for Lean-authored programs.
  5. Audit upstream compiler behavior at an immutable revision before assuming it works. A small Lean-authored Core0 backend is allowed when the upstream route is unsuitable; record why. Do not replace LLVM with a different backend to simplify the task.
  6. No target libc, libm, libgcc, compiler-rt, libuv, pthreads, C++ runtime, upstream Lean runtime, arbitrary foreign code, or undocumented stubs. Every intrinsic/helper must be supported, documented and accounted for. Unknown means reject, not pass.
  7. No sorry, admit, sorryAx, extra axioms, or native_decide used to certify a trusted property. Negative fixtures may mention forbidden constructs. Such fixtures must be quarantined and expected to fail, not imported into the trusted implementation.
  8. Preserve the difference between tests, proofs, audits, and physical measurements. Green scaffolding tests do not establish freestanding execution or compiler correctness.
  9. Do not silently broaden Core0's accepted language. Version contracts, add tests, and record any accepted feature with its semantics and lowering.
  10. Keep vendor hardware documents and firmware/ISA unknowns explicit. Supplier selection is not supply confirmation. Do not use guessed panel or controller specifications.
