serial.c:87-94,330-363,409-431,479-500,523-529 establishes the used side effects:

  • LSR at offset 5 observes DR 0x01, errors 0x1e, THRE 0x20, TEMT 0x40. Reading LSR clears BI/OE (0x12), preserving PE/FE (0x0c).
  • RBR at offset 0 consumes a FIFO byte and clears DR/BI when it empties.
  • THR at offset 0 writes a byte, clears THRE/TEMT, and starts backend transmission.
  • FCR 0x07 at offset 2 enables FIFO operation and resets receive/transmit FIFOs. Reset cannot retract bytes already delivered to the external backend.

The closed source constructors do not accept addresses or widths. The emitter uses one volatile i8 access with align 1, bracketed by core0_io_fence. The optimized audit accepts only alignment one or the exact power-of-two alignment implied by the constant address: 2^28 at RBR/THR, 2 at FCR, 1 at LSR. No source emitter alignment promise is strengthened. The machine audit verifies six lbu/sb sites and their 12 calls to the primitive whose body is exactly fence iorw,iorw; ret.

The finite Lean model makes access/fence events and bounded polling outcomes observable. Scripted LSR samples abstract asynchronous backend timing; the model does not reproduce FIFO capacity, all UART registers, backend retry scheduling, interrupt delivery, or a physical serial link. Packet/encoder probes and local lemmas have correspondingly local claims. QEMU execution separately tests receive, transmit, bounded timeouts, and request/response behavior.

The branch test initializes the RAM marker to 0x3c, then reads it through the compiled checked-RAM API after the selected branch. Its response carries the actual readback in bits 15..8 and the selector in bit zero. The host requires 0x5a00 with no raw UART prefix for false, and 0x3c01 with raw prefix a5 for true. Normalized source and pre/post LLVM reachability separately check exclusive effect placement.
