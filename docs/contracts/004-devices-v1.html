LemmaSim subordinate device/descriptor ABIs v1

Frozen with the first actual consumers. Authoritative numeric layout is profile JSON, generated by generate_constants.py. There is no second generic interface-description language. Host models are lemma_model.c; QEMU callbacks do transport only.

Control registers and sample fields are aligned little-endian64-bit. Aperture accesses are1..8bytes; unsupported/unaligned controls are rejected with error, unknown reads return0. Writes to read-only/unknown registers set invalid-operation error. Reset value1 is the only command. IRQs are level-triggered via actual PLIC sources12/13; masking belongs to PLIC. MMIO reads never acknowledge anything.

Paper at0x10010000, pen at0x10011000, each span4096. Device identity values are paper1280331856, pen1280331854, ABI1. Errors:1 invalid access/command, 2 wrong acknowledgement,3 malformed extent,4 Busy,5 sequence exhaustion, 6 interrupted refresh. Reset does not restart sequence numbering. Read paper SEQUENCE112 after reset to derive a fresh request number, including interrupted accepted requests.

Upload validates all dimensions before any target-RAM write:1..32 pixels each, contained rectangle, exact lengthceil(tile_width/2)*tile_height≤512. Coordinates may cover edge tiles; row packing uses the tile width. Upload only changes target RAM. Invalid uploads change no pixels. Refresh accepts one contained nonempty rectangle, mode1 fast or2 quality, and a nonzero strictly increasing request sequence. Busy submission sets error4 and never replaces the in-flight command. All accepted rectangle pixels are latched, so later uploads cannot race completion. Fast deterministically thresholds gray<8 to black, otherwise white. Quality preserves Gray4. Named timingsynthetic-paper-v1: fast2ms, quality25ms in virtual nanoseconds, provenance SYNTHETIC. Deadline overflow/sequence exhaustion fails.

Status bits Busy1, Completed2, Error4, Interrupted8. Visible RAM changes only at accepted deadline completion; completed sequence is the accepted request's sequence. IRQ asserts for Completed/Error/Interrupted, deasserting after valid acknowledgement unless Interrupted remains. Ack clears Completed/Error only. Warm reset cancels an in-flight operation, clears target/aperture to white and staged fields, retains completed visible RAM and sequence lifetime. An interrupted operation retains its old visible pixels but latches Interrupted: the affected physical result is marked unknown. Only a completed full-screen quality refresh clears Interrupted. New machine creation initializes both surfaces white. Cold reopening must redraw from guest documents even without retained panel bytes. Power cut is separate from reset.

FIFO capacity256. Head is immutable until exact-sequence acknowledgement, including concurrent arrivals; empty head reads return0. Epoch starts1, sequence starts1 and never wraps. Time is guest10MHz monotonic ticks. Coordinates0..65535; pressure0..queried maximum. Flags Contact1, Proximity2, Synthetic4, Disconnected8; tool0 unknown/1 pen/2 eraser; buttons low3bits. Capability1 advertises pressure range; no tilt is invented. Mouse ingress marks Synthetic and uses half-range contact pressure, explicitly not physical pressure measurement. Native QEMU input currently exposes ordinary absolute pointer/buttons; physical tablet pressure has not been exercised.

Status Data1, Loss2, Resync4, Error8. IRQ asserts for data/loss/error. Overflow, disconnection, invalid sample or reset discards queued followers and preserves the old immutable head as at most one diagnostic record, increments epoch/loss, latches out-of-band Loss and inhibits further ingress. The old head remains byte-stable across loss until exact head ACK or exact epoch LOSS_ACK. LOSS_ACK explicitly discards that old-epoch head; records must not be treated as drawing input while Loss is set. This prevents mixed fields during a concurrent overflow. The guest must end/cancel its current stroke, ack the exact epoch, then wait for a noncontact followed by fresh contact. A continuing held pen cannot fabricate a connecting line. Stale loss/head acknowledgements set error2. Counters saturate and exhaustion is an explicit error. Previously committed strokes are unaffected. A contact watchdog at10million ticks (1 synthetic second) after the last contact sample marks stream loss if no later release/contact update arrives; lost pen-up cannot leave an indefinite contact. After this boundary the user must lift and contact again. The watchdog is a versioned synthetic safety policy, not a physical tablet timeout measurement.

Headless raw input is the same serialized nine-word sample schema (72bytes), sequence1..N, epoch1, nondecreasing tick timestamps, at most1million records. Adapter rejects empty/truncated/out-of-order streams. Each raw record enters FIFO at virtual timetimestamp*100ns; ties preserve file order. Device assigns its own sequence/epoch. This input never accesses guest ink functions or application RAM. Optional raw-output captures every external ingress record, including rejected events, to a new file in that same input schema. Its sequence/epoch identify the external bridge stream (1..N/1); the controller assigns independent FIFO values. Native input already appears in QEMU record/replay: replay must not also inject its captured raw-output as a second source. Scheduled raw-file sessions identify and preserve their original file. Equal-time raw records retain file order; equal-time QEMU virtual timers follow stable arming order in the pinned timer list. No host sleeps choose guest event timestamps.

The binding sets DTB words at the actual reset-vector handoff, after finalizing its generated FDT; the descriptor is not a host-only manifest. Guest validates versions, checksum, envelopes, ranges and FDT consistency before normal operation. Low reservation is0x80000000..0x82000000, pool32MiB 0x82000000..0x84000000; exact guest image/package/metadata/stack reservations must lie inside the low envelope. DTB has an independent reservation at actual computed address. A declared pool is usable only after guest metadata/range support.
