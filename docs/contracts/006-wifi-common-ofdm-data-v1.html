Component interface and exact state

The circuitry runs on the declared100MHz digital clock, emitting signed16-bit complex Q14 I/Q with one valid strobe every5 clocks (20Msample/s), including symbol boundaries. Each symbol has a16-sample cyclic prefix and64-point integer IFFT. Forty-eight data tones are -26..26 excluding DC and pilots -21,-7,+7,+21. BPSK maps0 to-1 and1 to+1. The pilot sequence skips the SIGNAL polarity and starts at DATAp1, with base pilot signs(+,+,+,-). Q14 cosine ROM values are nearest integers to16384cos(2pi*k/64), extended by symmetry. Summation is divided by64 with arithmetic floor; the independent numeric bound is1.5LSB, derived from 52 coefficient quantization errors plus one floor error. This numerical bound is not a clock, physical EVM or RF signoff tolerance.

Local resource policy accepts1..16 payload bytes and appends a reflected IEEE CRC32 FCS (EDB88320, initial/final allones, least-significant octet/bit first). SERVICE is16 zero bits, then payload/FCS, six forced-zero BCC tail inputs and scrambled zero padding to24 input bits/symbol. The seven-bit nonzero scrambling state advances across the forced tail. K7 BCC emits133octal then171octal; new input enters registerbit6. The state carries between symbols. Maximum PSDU20 bytes, eight DATA symbols,182 useful terminated Viterbi steps. Padding is not used to change the known-zero terminal trellis state.

RX arm receives expected payload length and scrambler seed from an upstream PLCP authority, absent in this version. The first valid sample defines aligned CP start. There is no preamble acquisition, frequency/timing tracking, channel estimation, equalization or noisy-channel claim. After acquisition every sample must arrive exactly5 clocks later; early/late/drop strobes abort. No first sample within8192 clocks aborts. Dropping the first sample can instead cause pilot/FEC rejection because acquisition is not implemented. RX performs integer real DFT, hard decisions, deinterleaving, deterministic64-state Viterbi (ties choose lower predecessor), traceback from state0, SERVICE/CRC checks, and a local metric limit4. A clean-code bad FCS must reach CRC rejection, independently of FEC rejection.

One immutable16-byte RX head exists. Overflow preserves its bytes/length; ACK clears only validity, retaining old bytes until reset or replacement. New publication wins coincident ACK. New events win coincident W1C. Reset or disabled power clears all buffers, coding/DFT/trellis/survivor state, sample dividers, counters, events and head. Explicit cancel/coexistence withdrawal aborts in-flight TX/RX and preserves the published head. Coexistence arbitration itself is absent.

The leaf PIO interface has10-bit offsets, aligned64-bit accesses only, ready=1, error for disabled, unknown, wrong-width or invalid-value accesses. No SoC map is assigned. A rejected access raises fault1/event4 without changing its requested configuration. Configuration/staging writes while either direction is active raise fault2. Each TX submit captures its staged bytes privately before CRC.

Lean authority and bounded qualification

Codec.lean implements packet CRC, scrambling, BCC, interleaving and selected DATA-symbol coding state through genuinely checked scalar/bounded folds. The pure codec uses existing language contracts; it gains no device/runtime authority. The standalone M-mode development guest generates both payloads in its own RAM, computes known-answer records and eight DATA coding carries. The exact ELF is source-lowered/O2/object audited and runs on an unchanged qualified native RTL core. Host only copies its resulting octets into the two leaf PIO staging ports; this is not a guest-driven connected radio driver or0.12 integration claim.

Builds use unused outputs,300s bounds/two jobs; component runtime bound30s. The purecodec guest bound is5M native clocks/120 host seconds. Lake operations hold build/task006-lake.lock. Primary KAT, independent polynomial/delay/matrix and floating DFT oracles, two actual endpoint exchanges, descriptor bounds, correction, CRC/corruption/loss, reset/power/coex, head/IRQ collision and live coding-state forks are separate observations. Original FAILs remain retained. No synthesis/STA/DRC/LVS/RF or final Wi-Fi6 normative closure is inferred.
