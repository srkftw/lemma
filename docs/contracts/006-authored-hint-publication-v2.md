# Scoped course publication, version 2

`lemma-authored-hint-publication/2` connects the revision-bound authored-hint
filter to every current course publication. It corrects the incomplete first
integration: numeric entry used `ArithmeticAligned.render`, while opening,
ordinary workspace publication (including checker replies), and loss repaint
still called the historical sparse renderer, which used aggregate assistance.

The shared `renderPackageCourseScoped` calls `ArithmeticAligned.render` and
retains the same width read, 65 tile markings, dirty rectangle, status/error
propagation and framebuffer ownership. The three existing callers are
`publishPackageWorkspace`, `finishOpenPackageCourse` and
`numericPumpCancelledRedraw`. No journal, recovery, checking, source-selection,
or permission policy changes. The historical sparse declaration remains in
source; current selected artifacts replace that unreachable declaration with
the scoped publisher. Noncanonical geometry retains the existing aligned
renderer's sparse fallback.

`lemma-authored-hint-publication-artifact/2` is an additive exact artifact
cohort. Its genuine catalog contains the new scoped declaration and omits the
old reachable publisher. The first hint authority file and all earlier
authorities remain immutable. The new complete authority binds both the
original deployment role and the first hint artifact. It preserves root,
ABI/effect/device/loop checks and every complete pre/post corpus check. The
two read-only filter helpers are unchanged. Independent pre-LLVM checks require
all three publishers to call the scoped renderer, that renderer to invoke the
aligned filter path, and the filter to read event version208, count192,
revision40 and goal48 in order.

correct, but its pixels retained the prior revision's rational hint. That
failure is preserved. Passing component or linked-image checks for version1
does not qualify its incomplete connected hint behavior. Version2 requires
new genuine artifact and linked-image audits, then the retained connected
test with its original deadlines. It introduces no language/runtime extension,
new mathematical authority, live tutor, or physical claim.

```sh
python3 scripts/archive_guest_sources.py --build AUDITED_CANONICAL_ROLE \
  --source-root ORIGINAL_COMPLETE_SOURCES --output-dir UNUSED_ARCHIVE
```

The command admits only the existing exact profile0.3 ordinary notebook or
initializer configuration sets, copies the complete consumed inventory and
then runs `canonical_guest_archive`. USB and Product retain their separate
validators. This produces source bytes for reuse; it never runs recovery or
writes user media.
