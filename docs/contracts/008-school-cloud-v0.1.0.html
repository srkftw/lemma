Authority and record boundary

Definitions, private operational records, immutable content-addressed artifacts and rebuildable projections have distinct ownership. Course publication is immutable by course/edition; attempts retain definition, checker, policy and assistance provenance. All commands include the school and actor. The development binding trusts the local OS caller to identify the actor; it is not internet authentication. Explicit grants scope resource and action. Packages confer no filesystem or administrative effects.

Local commit and failure model

One OS-locked authority serializes operations. Both transport parent and Lean child retain the same open-file-description lock; parent termination cannot release authority while the child is committing. The default monotonic clock belongs to the current host boot; operational restoration is qualified in that same clock domain. Cross-boot/cross-host historical restoration requires a future clock-rebasing protocol and currently fails closed when uptime would roll the logical clock back. Fresh reusable import/clone starts a new clock. Artifact bytes are bounded, hashed in Lean, closed and renamed before any reference can commit. Each complete transaction writes a bounded snapshot to a private staging file, closes it and atomically renames it over the authoritative snapshot before acknowledging. Incomplete staging files are ignored and reclaimable. Recovery validates schema, sequence and artifact references before serving. This binding targets abrupt process termination with a functioning local filesystem; no host-crash, power-loss, replication or distributed consensus claim follows from close and rename.

Jobs and resources

Durable job states are queued, leased, completed or cancelled. Every assignment increments a fence and is bound to the current execution generation. Expiry uses host-boot monotonic milliseconds by default, with an explicit controlled-ms test clock, separate from learner observation time; rollback rejects. Restart changes generation before work admission. Old results reject even if their bytes are well formed. Interactive capacity is reserved separately from bulk/training queue admission. Cancellation never creates mathematical evidence. A local provider is the only implementation; remote provisioning, replicated availability and resident large-model services remain unsupported.

LocalProvider adds versioned private node/worker declarations, exact core0-v0.5/school-linear-worker/1 capabilities, controller identity, image digest, guest CPU/memory/buffer limits, reported health and drain state. Numerical leases require a current-generation ready-to-launch report, matching artifacts verified in local storage, exclusive worker ownership and bounded aggregate node reservations. Draining blocks new work while allowing existing ownership to complete. A changed health report or worker configuration supersedes active ownership; offline-to-ready cannot revive it. Identical health retries preserve their epoch. Node budget reconfiguration governs new admission while preserving existing reservations and completion. Reconciliation and reassignment restore eligible ownership without duplicate resources. Health is an authorized controller report; actual VM READY and response bytes are independent evidence. Declared reservations are not host cgroup enforcement, physical health attestation or replicated availability. Generic hosted jobs retain the global quota interface and do not assert an RV64 capability. Runtime registry identities stay out of reusable school packages. The provider evidence separates focused admission fixtures from actual registered RV64 job/load execution.

Client and evidence

Existing installed course and tutor-action contracts remain authoritative. The school binding independently checks school, enrollment, session, publication, policy, sequence, expiry and cancellation. A decision, upload admission, guest acceptance/rasterization and actual panel visibility are different observations. Drawing is the baseline; absent sensors are missing inputs. Synthetic tests are not human learning or physical-device evidence.

Numerical and release boundary

The bounded linear component has an explicit numerical contract and synthetic dataset identity. Hosted training and RV64 inference are separate claims. Unsupported shapes, operations and providers reject. No general tensor runtime, JAX parity, educational efficacy, production protection, public redistribution rights or physical conformance is claimed. The owner supplied the real archive; the complete catalogue and a source-derived binomial-square unit now have separate source-bound ingestion/authoring evidence. Original textbook bytes remain outside tracked source. No repository-wide license file is present; existing third-party notices retain their own scope.
