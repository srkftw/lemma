Train, evaluate, publish, select and roll back

The supported numerical consumer is a two-feature review-risk scorer with an authored/explainable baseline. A permitted dataset supplies explicit source, grant, independent label/transformation provenance, fixed disjoint group/record splits and the exact feature order. Each split has 1–4096 rows; training uses four-row batches, at most 100000 updates and bounded JSONL decoding. Missing independent assessment inputs retain the authored baseline. A supplied numerical configuration selects a positive immutable model version, finite learning rate in (0,0.25] and momentum in [0,0.95]. The actual Lean implementation, checkpoint state and Q10 parameter limits remain authoritative.

./scripts/lemma-school train --dataset DATASET_DIRECTORY --checkpoint CHECKPOINT.json \
  --output-dir TRAINED_DIRECTORY --steps 32 --configuration examples/school/training-config.json
./scripts/lemma-school evaluate --dataset DATASET_DIRECTORY --checkpoint CHECKPOINT.json \
  --output-dir EVALUATION_DIRECTORY --configuration examples/school/training-config.json
./scripts/lemma-school SCHOOL_ROOT publish-training --school SCHOOL --actor OPERATOR \
  --directory TRAINED_DIRECTORY --dataset DATASET_DIRECTORY --checkpoint CHECKPOINT.json \
  --configuration examples/school/training-config.json --rights 'EXPLICIT PERMITTED PROVENANCE'
./scripts/lemma-school SCHOOL_ROOT models --school SCHOOL --actor OPERATOR
./scripts/lemma-school SCHOOL_ROOT select-model --school SCHOOL --actor OPERATOR --version 9001
./scripts/lemma-school SCHOOL_ROOT rollback-model --school SCHOOL --actor OPERATOR --version PREVIOUS_VERSION \
  --reason 'Human-readable reason'
