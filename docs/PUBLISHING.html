Historical preparation

The starter was first prepared locally because the connection did not expose a repository-creation action and the runtime had no authenticated GitHub CLI. The owner subsequently created the repository. No credentials were requested in chat.

The ZIP and Git bundle supplied earlier are preparation snapshots. GitHub main is the canonical published starter; its publication notes and metadata supersede the preparation snapshots' statements that no remote exists.

Retained bootstrap helper

scripts/publish-github.sh and its mocked tests remain as auditable host-only tooling. The helper was designed to create a new private srkftw/lemma from a clean local source tree using an authenticated GitHub CLI. It refuses existing repositories, existing origins, dirty worktrees, the wrong account, and failed visibility checks.

Do not run the helper for this existing repository. Use ordinary branches and reviewable commits instead. Do not delete the repository to make the helper run. Its tests create temporary mock repositories and make no live GitHub requests.
