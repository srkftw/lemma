Native raw tablet transport

python3 scripts/lemmasim_tablet.py --list reads Linux input-device names without reading their event streams. A selected real digitizer can feed an existing persistent session:

python3 scripts/lemmasim_tablet.py --device /dev/input/eventN --session-dir build/lemmasim/my-session --record build/lemmasim/my-session/tablet-raw.jsonl

The current adapter supports Linux x86_64 evdev. It requires reported absolute X/Y, contact and a pen/eraser tool; touchpads and ordinary mice are rejected. The capability report includes actual ranges, pressure support, tool/buttons, reported but untransported axes, and an explicit integer coordinate/pressure normalization. Absent pressure is reported UNAVAILABLE and transports zero; no contact pressure or tilt is invented. Pen-v1 cannot carry tilt. Full physical registration/calibration and physical digitizer compatibility remain unverified.

Each SYN_REPORT transports one raw sample at the session's authoritative virtual time. Kernel timestamps and complete raw frame events are preserved separately; host wall time does not become guest time. SYN_DROPPED produces an explicit guest stream-loss boundary, discards incomplete events, and queries actual kernel state after the next synchronization. Disconnect/cancel also produces stream loss, allowing the real guest to cancel/resynchronize a stroke. Frames, capture size and lifetime are bounded, and capture paths are exclusive. The adapter performs no gesture, notebook, ink, journal or mathematical work. SIGTERM/SIGINT stop the input thread and attempt an explicit loss event before closing; bounded RPCs and teardown expose a blocked or failed sink. An operating system device handle is an external connection, not snapshot state. Snapshot creation does not drain input or inject a cancellation. Restore/replay must disconnect the live adapter before applying machine state; reconnection and loss are separately recorded external decisions.

Eight independent host fixtures include a real byte-pipe with fragmented event records, EOF cancellation, literal session admission and real child-process SIGTERM teardown. A physical tablet was not present in the observed Linux input inventory, so manual tablet writing/registration is NOT_RUN. EOF fixtures are transport tests, not physical-input evidence.
